Key Differences from Unity

Aspect: Unity vs PowerStore
- Connection Parameter: Unity uses unispherehost, PowerStore uses array_ip
- Username Parameter: Unity uses username, PowerStore uses user
- Initiator State: Unity uses present, PowerStore uses present-in-host
- Module: Unity uses dellemc.unity.host, PowerStore uses dellemc.powerstore.host
- Info Module: Unity uses dellemc.unity.info, PowerStore uses dellemc.powerstore.info
